# Auréa Collection | Semijoias

Site demonstrativo One Page desenvolvido em HTML, CSS e JavaScript puros.

- `index.html`: estrutura e conteúdo.
- `css/style.css`: identidade visual e responsividade.
- `js/script.js`: catálogo, menu mobile e links de compra pelo WhatsApp.

As imagens do catálogo e o logo estão na raiz do repositório. O código também prevê o vídeo `video-inicio.mp4`; se esse arquivo não estiver presente, o navegador mantém o poster do hero.

Os preços dos produtos são fictícios e servem apenas para demonstração.
